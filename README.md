
# SWYNEX C++ OOP Foundation

## Project: Student Information System

### Description
A simple C++ project demonstrating
Object-Oriented Programming concepts.

### Concepts Used
1. Classes and Objects
2. Constructors
3. Encapsulation
4. Inheritance

### Technologies
- C++
- VS Code
- GitHub

### How to Run

Compile:
g++ main.cpp -o student_app

Run on Windows:
student_app.exe

### Project Objective
To understand and implement basic OOP
concepts using a simple student information
system.
